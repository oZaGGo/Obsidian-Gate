Commands

Executable commands directly from the in-game chat. All commands must start with the . prefix.

.echo

Repeats the provided message back to the server chat, identifying the original sender.

Usage: .echo [message]

.info

Toggles the real-time system metrics broadcast (CPU & RAM usage) every 3 seconds.

Usage: .info <start> | <stop>

.tps

Toggles the real-time calculated "tps" (ticks per second).

Usage: .tps <start> | <stop>

.ask

Interact with the Integrated AI for general assistance.

Usage: .ask [question]
